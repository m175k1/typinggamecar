# 🏎️ Typing Speed Racer

A lightweight typing speed game built with vanilla HTML, CSS, and JavaScript. No frameworks, no dependencies.

**[▶ Play it live](https://YOUR-USERNAME.github.io/typing-speed-racer/)**

## Features

- Live WPM, accuracy, and timer tracking
- Character-by-character feedback (green = correct, red = wrong)
- Animated car that moves as you type
- 3 difficulty levels: Easy, Medium, Hard
- Dark mode support

## How to play

1. Select a difficulty
2. Click **Start**
3. Type the quote as fast and accurately as you can
4. Your WPM, accuracy, and time are shown when you finish

## Deploy to GitHub Pages

1. Push this folder to a GitHub repository
2. Go to **Settings → Pages**
3. Set source to **Deploy from a branch → main → / (root)**
4. Your game will be live at `https://YOUR-USERNAME.github.io/REPO-NAME/`
